## Purpose

Описывает работу с задачами в объёме MVP: кому задача принадлежит, какие у неё статус и срок, и как она связана со страницей.

## ADDED Requirements

### Requirement: Задача принадлежит одному владельцу

Каждая задача SHALL иметь ровно одного владельца — пользователя, который её создал. Владелец является и исполнителем задачи. Система MUST NOT позволять назначать на задачу дополнительных пользователей.

#### Scenario: Создание задачи

- **WHEN** авторизованный пользователь создаёт задачу
- **THEN** владельцем задачи становится этот пользователь
- **AND** назначение других исполнителей недоступно в интерфейсе и через API

#### Scenario: Задачи другого пользователя недоступны

- **WHEN** пользователь запрашивает список своих задач
- **THEN** система возвращает только задачи, владельцем которых он является

#### Scenario: Попытка обратиться к чужой задаче

- **WHEN** пользователь запрашивает или изменяет задачу, владельцем которой он не является
- **THEN** система отклоняет запрос и не раскрывает содержимое задачи

#### Scenario: Анонимный доступ к задачам

- **WHEN** неавторизованный посетитель обращается к задачам
- **THEN** система отклоняет запрос: задачи не входят в публичный read-only доступ к странице

### Requirement: Задача имеет статус из фиксированного набора

Задача SHALL иметь ровно один статус из набора `TODO`, `IN_PROGRESS`, `DONE`. При создании задаче MUST присваиваться статус `TODO`, если статус не указан явно.

#### Scenario: Статус по умолчанию

- **WHEN** пользователь создаёт задачу без указания статуса
- **THEN** задача получает статус `TODO`

#### Scenario: Смена статуса

- **WHEN** владелец меняет статус задачи на одно из допустимых значений
- **THEN** система сохраняет новый статус

#### Scenario: Недопустимый статус

- **WHEN** запрос содержит статус вне набора `TODO`, `IN_PROGRESS`, `DONE`
- **THEN** система отклоняет запрос с ошибкой валидации и не изменяет задачу

### Requirement: Срок выполнения необязателен

Задача MAY иметь срок выполнения. Отсутствие срока SHALL быть допустимым состоянием и не препятствовать созданию или изменению задачи.

#### Scenario: Задача без срока

- **WHEN** пользователь создаёт задачу, не указывая срок
- **THEN** задача создаётся успешно и отображается без срока

#### Scenario: Просроченная задача

- **WHEN** у задачи задан срок, он находится в прошлом и статус задачи не `DONE`
- **THEN** система отмечает задачу как просроченную

### Requirement: Связь задачи со страницей необязательна

Задача MAY быть привязана к одной странице. Задача без привязки SHALL оставаться полноценной: она доступна владельцу в общем списке задач. Привязка допустима только к странице, владельцем которой является владелец задачи.

#### Scenario: Личная задача без страницы

- **WHEN** пользователь создаёт задачу, не указывая страницу
- **THEN** задача создаётся и доступна в общем списке задач владельца

#### Scenario: Задача, привязанная к странице

- **WHEN** владелец привязывает задачу к своей странице
- **THEN** задача остаётся в общем списке и дополнительно связана с этой страницей

#### Scenario: Привязка к чужой странице

- **WHEN** пользователь пытается привязать задачу к странице, владельцем которой он не является
- **THEN** система отклоняет запрос

#### Scenario: Удаление связанной страницы

- **WHEN** владелец удаляет страницу, к которой привязаны задачи
- **THEN** задачи сохраняются и становятся задачами без привязки к странице

### Requirement: Задача и блок типа `todo` — разные сущности

Система SHALL различать задачу и блок типа `todo`. Блок `todo` является элементом содержимого страницы с бинарным состоянием и существует только внутри неё. Задача является самостоятельной сущностью со статусом из трёх значений и необязательным сроком, доступной в сквозном списке. Отметка блока `todo` MUST NOT создавать или изменять задачу.

#### Scenario: Отметка блока `todo` не затрагивает задачи

- **WHEN** пользователь отмечает блок типа `todo` на странице
- **THEN** изменяется только содержимое блока
- **AND** список задач пользователя остаётся без изменений

#### Scenario: Задача не отображается как блок страницы

- **WHEN** пользователь создаёт задачу, привязанную к странице
- **THEN** содержимое страницы не изменяется и новый блок не создаётся
