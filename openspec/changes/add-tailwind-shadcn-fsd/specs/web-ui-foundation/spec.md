## Purpose

Обеспечивает единую UI-основу web-приложения для последующей продуктовой разработки: utility-стили, доступные примитивы интерфейса, class-based тёмная тема и минимальный smoke UI на главной странице.

## ADDED Requirements

### Requirement: Главная страница отображает smoke UI

Главная страница web-приложения MUST отображать заголовок приложения, текстовое описание готовности UI-стека, поле ввода и кнопку действия.

#### Scenario: Smoke UI рендерится при открытии главной страницы

- **WHEN** пользователь открывает главную страницу web-приложения
- **THEN** отображается заголовок «Lite Notion»
- **AND** отображается текстовое поле ввода
- **AND** отображается кнопка с доступным именем для взаимодействия

#### Scenario: Smoke UI доступен для assistive technologies

- **WHEN** главная страница рендерится в тестовом окружении
- **THEN** заголовок доступен как heading
- **AND** поле ввода доступно как textbox
- **AND** кнопка доступна как button

### Requirement: Class-based тёмная тема поддерживается на уровне документа

Web-приложение MUST поддерживать class-based тёмную тему через класс `dark` на корневом HTML-элементе и MUST учитывать системные предпочтения пользователя при отсутствии явного выбора темы.

#### Scenario: Системная тёмная тема применяется без явного переключателя

- **WHEN** корневой layout смонтирован с провайдером темы
- **AND** пользователь не выбирал тему явно
- **THEN** приложение MUST использовать системные предпочтения для выбора светлой или тёмной темы

#### Scenario: Класс dark активирует тёмные design tokens

- **WHEN** на корневом HTML-элементе установлен класс `dark`
- **THEN** страница MUST использовать тёмные CSS design tokens приложения

### Requirement: Публичный UI API изолирован от vendor-кода shadcn

CLI-managed компоненты shadcn MUST располагаться в `shared/ui/shadcn`. Для каждого используемого
vendor-компонента приложение MUST предоставлять кастомизируемую обёртку в `shared/ui`, а публичный
модуль `@/shared/ui` MUST экспортировать обёртки, а не vendor-компоненты напрямую. Прикладной код
MUST импортировать базовые UI-примитивы только через этот публичный модуль.

#### Scenario: Smoke UI использует публичный UI API

- **WHEN** smoke UI на главной странице импортирует Button и Input
- **THEN** импорты MUST идти из `@/shared/ui`
- **AND** экспортируемые Button и Input MUST быть проектными обёртками над компонентами из
  `shared/ui/shadcn`

#### Scenario: Обновление vendor-компонента сохраняет проектные стили

- **WHEN** компонент в `shared/ui/shadcn` добавляется или перезаписывается через shadcn CLI
- **THEN** соответствующая обёртка в `shared/ui` MUST оставаться отдельным файлом
- **AND** проектные стили и значения по умолчанию в обёртке MUST сохраняться

#### Scenario: Обёртка принимает дополнительный className

- **WHEN** потребитель передаёт `className` в публичный Button или Input
- **THEN** обёртка MUST объединять его со своими проектными стилями
- **AND** остальные поддерживаемые свойства MUST передаваться vendor-компоненту
