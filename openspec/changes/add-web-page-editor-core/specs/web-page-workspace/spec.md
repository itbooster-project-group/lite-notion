## MODIFIED Requirements

### Requirement: Доступность и состояния данных

Дерево ДОЛЖНО (MUST) использовать `tree`/`treeitem`, клавиатурную навигацию и доступные имена. Состояния загрузки, ошибки и пустого списка ДОЛЖНЫ различаться; ошибка ДОЛЖНА предоставлять повтор без сырых деталей backend. Мобильная навигация ДОЛЖНА закрываться по Escape с восстановлением фокуса. Контент активной страницы ДОЛЖЕН показывать хлебные крошки, заголовок и редактор соответствующего PageDocument. Корневой маршрут и проект без активной страницы НЕ ДОЛЖНЫ запрашивать PageDocument.

#### Scenario: Работа с клавиатурой

- **КОГДА** фокус находится внутри дерева
- **ТОГДА** пользователь может раскрывать узлы, активировать и переименовывать страницу, а также выполнить доступное перемещение без указателя

#### Scenario: Открытие активной страницы

- **КОГДА** пользователь открывает доступный `/pages/{pageId}`
- **ТОГДА** рабочая область сохраняет breadcrumbs и heading, загружает PageDocument этой страницы и показывает editor content

#### Scenario: Открытие проекта без активной страницы

- **КОГДА** пользователь открывает `/projects/{projectId}` либо корневой маршрут
- **ТОГДА** рабочая область не запрашивает PageDocument и показывает прежний project либо root content

#### Scenario: Ошибка документа активной страницы

- **КОГДА** workspace metadata загружены, но PageDocument получить нельзя
- **ТОГДА** ошибка и повтор отображаются в области редактора без скрытия navigation, breadcrumbs и page heading
