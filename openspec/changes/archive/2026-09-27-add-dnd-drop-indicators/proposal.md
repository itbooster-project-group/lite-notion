## Why

Перетаскивание страниц мышью в дереве навигации и в `/projects/{projectId}` не позволяло поставить страницу рядом с другой на том же уровне и не давало никакой визуальной обратной связи о месте вставки. Отладка в браузере выявила три причины:

1. В конфигурации `useTree` обоих деревьев не был включён `canReorder`, поэтому `@headless-tree/core` вообще не вычислял позиции «перед»/«после» элемента — любой drop трактовался как «сделать дочерним».
2. `toMoveIntent` для цели «в конец родителя» считал индекс с учётом самой перемещаемой страницы, тогда как `isMoveIntentValid` считает siblings без неё. Библиотека проверяет именно эту цель перед разрешением вставки рядом с соседом, поэтому перестановка среди siblings всегда отклонялась (на другом уровне — с другим родителем — проверка проходила).
3. Для корневых страниц родителем в дереве навигации является проект, а адаптер drop-цели возвращал `null` для неупорядоченной цели-проекта, поэтому перестановка на корневом уровне тоже отклонялась.

Кроме того, нигде не рендерился `tree.getDragLineData()`/`getDragLineStyle()`, поэтому место вставки не было видно.

## What Changes

- Включить `canReorder` в обоих деревьях, чтобы верх/низ строки означали вставку перед/после неё.
- Исправить расчёт индекса «в конец родителя»: `PageDropTarget` типа `item` несёт список id детей, а `toMoveIntent` считает индекс без перемещаемой страницы — так же, как `isMoveIntentValid`.
- Разрешить проект как родителя-цель в дереве навигации: drop на строку своего проекта делает страницу последней корневой страницей этого проекта; перенос в другой проект по-прежнему запрещён. **BREAKING для спеки**: снимается запрет «проекты не должны быть целями DnD страниц» — библиотека использует одну и ту же проверку для «drop на проект» и «вставить рядом с корневой страницей», поэтому разделить их нельзя.
- Рендерить одну линию вставки (`TreeDropIndicator` в `shared/ui`) в обоих деревьях по `tree.getDragLineStyle()`.
- Без изменений: клавиатурный DnD, диалог «Переместить…», серверный API перемещения.
- **Вне scope**: расширение жеста «reparent» (перенос на более высокий уровень перетаскиванием влево) сверх встроенной эвристики `@headless-tree` (свёрнутый последний элемент группы); для произвольного уровня остаётся диалог «Переместить…» и drop на строку проекта.
- **Вне scope**: индикатор вставки при перетаскивании блоков редактора — выносится в отдельный change.

## Capabilities

### New Capabilities
(none)

### Modified Capabilities
- `web-page-workspace`: проект становится допустимой drop-целью своих страниц; перестановка на одном уровне через верх/низ строки; единая линия вставки в обоих деревьях.

## Impact

- Только frontend, без изменений API/схемы: `apps/web/src/entities/page` (`PageDropTarget`, `toMoveIntent`), `apps/web/src/widgets/workspace-navigation`, `apps/web/src/features/workspace-management/ui/page-tree.tsx`, `apps/web/src/shared/ui` (новый `TreeDropIndicator`).
- Новых зависимостей нет: `@headless-tree/core` уже содержит нужные API.
