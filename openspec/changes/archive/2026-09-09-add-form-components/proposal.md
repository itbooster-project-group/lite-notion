## Why

Формам нужен единый доступный MVP-набор контролов с предсказуемыми состояниями и публичными типами. Сейчас Button содержит проектное поведение внутри generated shadcn-модуля, а Label, Textarea, Checkbox и Select не имеют проектного API.

## What Changes

- Разделить библиотечные shadcn Base UI-компоненты в `src/shared/ui/shadcn` и проектные обёртки в `src/shared/ui`; перенести Tooltip-поведение Button в обёртку.
- Доработать Button и Input, добавить Label, Textarea, Checkbox и Select; экспортировать шесть компонентов и их публичные типы через `@/shared/ui`.
- Определить размеры, variants, disabled, loading, error и empty для применимых контролов, сохранив существующие defaults Button и Input.
- Поддержать в Select одиночный и множественный выбор с независимо включаемым локальным поиском.
- Сохранить семантику, доступные имена, клавиатуру, управление фокусом и совместимость с формами.
- Добавить детерминированные Vitest/RTL-тесты проектного поведения и проверку границ импортов.
- Вне scope: массовая миграция продуктовых форм, переработка существующих overlay-компонентов, удалённый поиск, создание вариантов, виртуализация, новая система валидации и редизайн приложения.

## Capabilities

### New Capabilities

- `shared-form-controls`: публичный UIKit форм, состояния, доступность и четыре режима Select.

### Modified Capabilities

Нет: требования существующих продуктовых сценариев не меняются.

## Impact

- Frontend: `apps/web/src/shared/ui`, библиотечные компоненты в `shadcn/`, co-located тесты и проверка импортов web-кода. Существующие потребители Button/Input сохраняют API и поведение.
- Используются существующие shadcn с preset `base-mira`, Base UI, lucide-react и Vitest/RTL. Новые runtime-зависимости не планируются.
- Backend, API, БД, realtime и инфраструктура не затрагиваются.
