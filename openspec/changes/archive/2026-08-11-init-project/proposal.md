## Why

Проекту нужна единая воспроизводимая основа, на которой frontend- и backend-команды смогут начинать разработку без ручной настройки окружения и разрозненных команд. Базовый монорепозиторий должен обеспечить согласованные инструменты сборки, проверки типов, линтинга и тестирования до появления продуктовой функциональности.

## What Changes

- Создать pnpm workspace с приложениями `apps/web` на Next.js и `apps/api` на NestJS.
- Добавить общие корневые команды для разработки, сборки, линтинга, проверки типов и тестирования.
- Настроить общий TypeScript baseline, Biome и Vitest для обоих приложений.
- Добавить минимальные технические страницы и endpoint, позволяющие проверить запуск приложений, без продуктовой логики.
- Добавить русскоязычный README с требованиями к окружению и инструкциями запуска.
- Добавить англоязычные scoped `AGENTS.md` с общими и app-specific инструкциями для совместимых coding agents.
- Сохранить существующую конфигурацию OpenSpec как источник требований и задач проекта.
- Не включать PostgreSQL, Redis, Docker, авторизацию, CI/CD и продуктовые возможности: они будут оформлены отдельными изменениями.

## Capabilities

### New Capabilities

Нет. Изменение создаёт только инженерную основу и не добавляет наблюдаемого продуктового поведения.

### Modified Capabilities

Нет.

## Impact

- **Frontend:** появится минимальное приложение Next.js с App Router, TypeScript и базовым тестом React Testing Library.
- **Backend:** появится минимальное приложение NestJS с техническим endpoint `GET /health` и базовым тестом.
- **Инфраструктура разработки:** появятся pnpm workspace, общий набор npm scripts, Biome, TypeScript typecheck, Vitest и lockfile.
- **Документация:** появятся README на русском языке для команды и иерархия англоязычных `AGENTS.md` для совместимых coding agents.
- **Публичные API и данные:** продуктовые API, схемы данных и внешние интеграции не затрагиваются.
