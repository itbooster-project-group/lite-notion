## Why

Участникам команды, которые планируют и реализуют изменения с coding agents, не хватает единого человекоориентированного описания OpenSpec workflow. Текущий README показывает только `openspec list`, а полная последовательность действий и различия команд между поддерживаемыми агентами доступны лишь во внутренних инструкциях.

## What Changes

- Добавить отдельный русскоязычный практический гайд по OpenSpec lifecycle для Codex, Claude Code, Cursor и OpenCode.
- Дополнить README кратким входом в workflow и ссылкой на гайд.
- Согласовать корневые инструкции для агентов с описанными правилами human review, значимых документационных изменений и архивирования.
- Зафиксировать совместимую версию OpenSpec CLI и правила её обновления.
- Не изменять приложения, публичные API, зависимости, generated agent commands и продуктовые требования.

## Capabilities

### New Capabilities

Нет. Изменение добавляет только командную документацию и не создаёт наблюдаемого поведения продукта.

### Modified Capabilities

Нет.

## Impact

- **Документация:** появится новый гайд, а раздел OpenSpec в README станет точкой входа для участников команды.
- **Agent guidance:** корневой `AGENTS.md` будет согласован с human-facing workflow без изменения app-specific правил.
- **Frontend и backend:** код, тесты и конфигурация приложений не затрагиваются.
- **Инфраструктура и зависимости:** package manifests, lockfile и сгенерированные OpenSpec integrations не изменяются.
